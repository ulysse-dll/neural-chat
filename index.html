Comment ça marche

Un modèle de langage ne fait qu'une chose, en boucle : deviner le prochain token. Chaque mot que tu vois passe par ces étapes.
1 · Découpage en tokens—
Le texte est découpé en tokens : des morceaux de mots (« capit » + « ale »). Toute la conversation est relue à chaque message : c'est le contexte.
2 · Lecture du contexte—
Avant d'écrire, le modèle lit tout le contexte d'un coup (« prefill »). C'est l'attente avant le premier mot.
3 · Couches—
Chaque token traverse toutes les couches. Dans chaque couche, l'attention regarde les mots précédents, puis le MLP (des milliers de neurones) transforme l'information.
4 · Probabilités—
À la sortie, le modèle donne une probabilité à chaque token de son vocabulaire. L'incertitude (entropie) mesure à quel point il hésite.
5 · Tirage—
Il ne prend pas toujours le plus probable : il tire au sort parmi les meilleurs. La température règle l'audace, top-p le nombre de candidats gardés.
6 · Token écrit—
Le token choisi est ajouté au texte, puis tout recommence pour le suivant. Survole un mot de la réponse pour voir ses alternatives.
7 · Mémoire—
Pour ne pas tout recalculer, le modèle garde le résultat de chaque token déjà lu (le cache KV). Il grossit avec la conversation.

CPU : le processeur (6 cœurs, une barre par cœur). RAM : la mémoire, où le modèle entier doit tenir. GPU : la puce graphique. Sur ton Mac, elle est trop faible pour les modèles, qui tournent donc sur le CPU.

Neurones · 24 couches × 4 864

1 pixel = 1 vrai neurone du MLP. Couleur chaude : activé, froide : inhibé. Une case = une couche, de 0 (haut gauche) à 23. Clique pour agrandir, élargis le panneau pour voir plus de couches par ligne.
Ce sont les vraies valeurs calculées pour le token en cours, pas une animation. Les premières couches réagissent à la forme des mots, les dernières préparent le mot suivant.

Ce que chaque couche change

Hauteur = combien chaque couche modifie la représentation du token. Les dernières couches travaillent le plus : elles décident du mot.
